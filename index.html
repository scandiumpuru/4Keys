HOW TO PLAY

●
TAP / SCRATCH

対応キーを押す。階段配置ではキーを押したまま隣のキーを押しても、次のTAPを取れる。

━
HOLD

始点で押し、終点まで押し続ける。終点まで押せていれば成功。

➜
FLICK

始点から指定方向の隣キーへ。始点を離して押し直しても、押したまま擦ってもOK。

FLICKの方向
F → G
G → F / H
H → G / J
J → H
TAPの擦りは隣レーンへの入力で判定。FLICKは譜面で指定された方向への入力が必要。

譜面JSON

階段TAP、HOLD、FLICKを編集できます。timeは曲開始からの秒数。

譜面形式
{
  "title": "Scratch Steps",
  "bpm": 120,
  "duration": 30,
  "notes": [
    { "type": "tap", "lane": 0, "time": 2.0 },
    { "type": "tap", "lane": 1, "time": 2.25 },
    { "type": "hold", "lane": 2, "time": 3.0, "end": 4.0 },
    { "type": "flick", "lane": 2, "to": 3, "time": 5.0 }
  ]
}

lane: F=0, G=1, H=2, J=3。FLICKのtoもレーン番号。TAPは同時押しも可能。
